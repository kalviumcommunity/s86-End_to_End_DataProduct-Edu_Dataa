Contains reusable Python scripts for data processing and analysis.

- `normalize_vectorized.py`: demonstrates NumPy vectorization for min-max normalization and compares it against a loop-based implementation.
- `distribution_analysis.py`: computes skewness and kurtosis, plots histograms and KDE, and compares high-value versus low-value revenue segments for business distribution analysis.
- `correlation_analysis.py`: computes Pearson and Spearman correlation matrices, plots heatmaps, identifies top feature pairs, and explains why correlation does not imply causation.
 feature/behavioral-segmentation
- `groupby_aggregation.py`: demonstrates Pandas groupby aggregation by segment, ranking customer types, generating pivot tables, and surfacing actionable segment insights.
- `time_series_analysis.py`: computes rolling averages, resamples revenue by week and month, calculates period-over-period changes, and visualizes trend and cumulative metrics.
- `behavioral_segmentation.py`: computes segment metrics and visualizes comparisons with heatmaps and box plots for customer behaviour analysis.
